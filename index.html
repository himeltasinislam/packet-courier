Pick a protocol to start the round. Both lanes run at the same time so you can compare them.

What you are seeing
TCP laneHandshake first (SYN, SYN-ACK, ACK). Every data packet is acknowledged. Lost packets are resent after a timeout, the sending window shrinks after a loss, and the receiver hands data to the app strictly in order. Nothing is lost, but one lost packet stalls everything behind it.
UDP laneNo handshake, no ACKs, no resends. Packets are fired and forgotten. Fast and low latency, but whatever the network drops is gone.
ColoursGreen cell: arrived in time. Amber cell: arrived too late to be useful. Red cell: never arrived. Red ✕ in the lane: dropped by the network. Ringed dot: TCP retransmission.

Browsers cannot open raw TCP or UDP sockets, so this page runs an in-page simulation of both protocols (loss, delay, jitter, ACKs, retransmission timeouts, slow start). The repository also contains server.py and client.py, which use real TCP and UDP sockets.
